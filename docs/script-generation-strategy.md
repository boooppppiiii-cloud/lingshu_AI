# 社媒脚本生成策略

> 状态：产品策略与后续开发验收基线  
> 更新：2026-08-02  
> 来源：团队策略稿《脚本生成策略设计文档》（2026-07-31）

## 目标与定位

灵枢的默认服务对象是外贸工厂，首期重点为美妆护肤 OEM / ODM / Private Label 企业。脚本的目标是通过海外社媒建立采购信任并促成可验证的 B 端行动，而不是默认转化终端消费者。

主受众包括品牌创始人、产品负责人、采购人员、进口商、经销商和美容渠道采购决策人。

## 策略组合

脚本不应被定义为“一个按钮对应一个 Prompt”，而应由以下字段组合：

`生成层级 × 生成模式 × 内容主题 × 合作路线 × 买家角色 × 市场/语言 × 已验证事实与证据 × CTA`

### 已确认决策：路线与主题独立

合作路线与内容主题是两个独立维度，**不得互相作为脚本合法性的准入条件**。

- 合作路线只提供商业目标、默认买家角色、默认主 CTA 和已验证承接渠道。
- 内容主题只提供钩子、信息顺序、镜头功能和其自身所需的事实/证据约束。
- 最终主脚本以“路线策略 + 主题叙事 + 模式边界 + 已确认事实”进行结构化拼接。
- 主题的脚本准入只校验是否具备该主题的最低画面素材（产品信息模式可用“建议补拍”画面计划满足）。一旦具备，不因缺认证、MOQ、案例、趋势来源等高风险事实而阻止主题生成。
- 最低画面素材按“镜头功能组合”判断，不按上传文件数量判断。例如供应能力需要生产/流程、质检或履约动作之一；产品实证需要产品可识别画面，且有细节或演示动作之一。
- 上述组合是主题的理想画面覆盖，不是素材合法性或生成阻断条件。素材库中只要有相关产品素材，系统就必须基于现有素材调整脚本；缺少完美匹配镜头时只提示“选择其他素材 / 创建建议补拍”，不得判定素材不合法或阻止生成、成片。
- 在“AI 创作工作台 → 视频模式 → 素材库智能生成”中点击“创建建议补拍”后，任务必须同步进入“灵感大屏 → 待拍 Tab”队列，而不是停留在当前分镜内。任务固定标记为“脚本缺口”，并保留产品、主题、待补镜头功能、拍摄说明、建议时长、作品集来源和来源草稿/分镜。
- 在待拍任务中上传素材后，不得自动修改来源草稿。素材仅附着在任务中；用户点击“一键回填”后，才回填至仍存在的来源分镜，且不重写整条脚本。来源草稿或分镜已变化时，不做猜测性回填。
- 待拍任务上传的补拍素材自动进入企业自己的素材库，保留待拍任务和作品集来源关系，并由 AI 自动打标；它可被企业内其他作品复用，不只绑定来源任务。
- 所有画面功能标签均由 AI 自动识别并直接作为主题最低素材判断依据，不要求用户逐条确认。高风险事实主张仍需遵守事实与发布校验；素材标签本身不承担事实确认职责。
- 高风险事实只校验其对应主张：自动生成时缺失则不写成事实，转为待确认项或移除；不因“某路线通常不使用某主题”而拒绝生成。系统不替客户决定是否发布。

### 生成层级

1. `primary_script`：生成主脚本，确定钩子、分镜、证据、口播方向和 CTA。
2. `rewrite`：优化、重写、差异化或合规修复；默认继承主题、事实和已确认结构。
3. `derivative_voiceover`：提取口播、字幕和多语版本；不得重新创作视频逻辑或新增事实。

### 生成模式

1. `product_info`：依据产品资料生成可执行分镜。允许创意拍法，但不得把创意画面当企业既有事实。
2. `asset_library`：依据现有素材生成；素材决定画面边界，不能编造不存在的动作、人物、场景或结果。
3. `viral_remix`：依据对标视频逐镜分析进行受约束迁移；保留结构与节奏，不迁移竞品事实。
4. `inspiration_board`：用于前置创意和结构借鉴，可产出口播或分镜。

爆款裂变只在对标视频完成全片、连续的逐镜分析后生成；不得依据部分分析猜测、补全未识别镜头或生成裂变脚本。完成后系统在后台静默选择迁移强度：产品展示逻辑相近时尽量保留时间轴、镜头功能和节奏；跨品类但结构可用时保留钩子与信息顺序并重建动作/场景；只能借鉴创意时仅保留钩子机制和证明位置。前端不展示“高保真复刻 / 结构迁移 / 机制借鉴”名称，不要求用户选择；无论强度，竞品品牌、参数、口播、字幕、CTA、人物身份和客户事实均不得迁移。

### 内容主题

- 买家痛点：顾虑 → 判断难点 → 证据 → 询盘。
- 产品实证：判断问题 → 实物细节 → 资料/规格证据 → 采购价值。
- 使用场景：明确人物/场景 → 使用动作 → 可见细节 → 适用建议。
- 供应能力：供应风险 → 工厂/质检/产能证据 → 采购意义 → 询盘。
- 定制能力：品牌/渠道适配 → 已确认定制项 → 样品或版式动作 → 定制需求。
- 选型对比：选型场景 → 统一比较维度 → 差异与适用条件 → 选型咨询。
- 客户案例：已授权背景 → 已核实问题 → 过程 → 已确认结果 → 案例咨询。
- 趋势热点：有来源的信号 → 买家意义 → 企业产品证据 → 讨论需求。
- 真人口播：以真实出镜素材为主，要求人物动作、口型、台词与时长匹配。

### 九个主题的后台 B2B 钩子卡

以下规则只参与后台脚本组装，不在前端展示策略、评分或调节项。路线只提供商业目标和 CTA；主题决定前 1–3 秒的买家问题、画面钩子和信息推进。

| 主题 | 前 1–3 秒的买家问题 | 优先视觉钩子 | 禁止的生成表达 |
| --- | --- | --- | --- |
| 买家痛点 | 怎样避免一个具体采购/使用判断失误？ | 样品/包装并列、可见反差、问题卡 | 虚构损失、恐惧营销、\"姐妹们\"、\"闭眼入\" |
| 产品实证 | 除产品图外，怎样确认实物细节或规格？ | 开箱、标签、细节、真实演示 | 未证实功效、\"立竿见影\"、\"顶级品质\" |
| 使用场景 | 哪类场景或渠道能这样使用/陈列？ | 完整使用动作、陈列、上手操作 | 把体验画面说成疗效、销量或市场热度 |
| 供应能力 | 如何看见生产、质检或履约相关动作？ | 生产、包装、质检、仓储动作 | \"全球第一\"、\"永不延期\"、未证实规模 |
| 定制能力 | 哪个已确认产品/包装触点可被调整？ | 样品、标签、包装版式、规格组合 | \"什么都能定制\"、未经确认的交期/打样承诺 |
| 选型对比 | 应以什么真实维度在两种方案间选择？ | 可识别对象并列、同维度对照 | 贬低竞品、编造优势或价格差 |
| 客户案例 | 一个获授权的合作路径解决了什么问题？ | 许可的过程或结果材料 | 评论/聊天截图当案例、虚构客户合作 |
| 趋势热点 | 一个带来源的变化对买家决策意味着什么？ | 来源卡、时间线、产品关联画面 | \"全网都在买\"、单帖/评论当趋势 |
| 真人口播 | 已识别的出镜人如何回答一个具体问题？ | 真人讲解、拿样、演示 | 虚构创始人、专家或客户身份 |

统一避免 `premium quality`、`best seller`、`game changer`、`must-have`、`limited time`、`buy now`、`everyone loves it`、`guaranteed results` 等无法由当前企业事实支持的模板化表达。

主题 Prompt 采用“共享底座 + 主题约束卡”组合：共享底座统一处理企业事实、素材边界、路线、买家、主 CTA、平台和时长；主题约束卡只处理钩子、证明顺序、镜头功能、可用画面与禁用表达。主题不得选择、改写或推导 CTA；结尾只使用当前草稿的唯一主 CTA。九个主题不分别维护九套完整大 Prompt，也不以主题/路线组合决定脚本是否合法。

### 主题脚本版本

在 `AI 创作工作台 → 视频模式 → 选择主题/分镜` 中，切换主题不会覆盖当前主题脚本。当前脚本默认保留；用户点击“生成可执行分镜”后，为新主题创建新的主题脚本版本，供用户分别查看、编辑和继续制作。

主题脚本默认命名为“`主题 · 买家（序号）`”，例如“`买家痛点 · 美国采购版（1）`”。序号在同一主题、同一买家命名范围内递增，用于区分多次生成的脚本版本。

三条合作路线统一沿用当前产品默认主 CTA：“引导跳转 WhatsApp 以触达”。只有企业已配置并验证 WhatsApp 时，系统才可将它预填进新脚本；否则不自动生成该 CTA。

## 生成前策略 Brief

模型不得只接收原始产品资料。策略层必须先构造并保存结构化 Brief；模型只能在其中已确认的路线、事实、证据与 CTA 范围内创作。

```json
{
  "generation_layer": "primary_script",
  "generation_mode": "product_info",
  "content_theme": "customization",
  "cooperation_route": "oem_odm",
  "target_buyer_role": ["brand_founder"],
  "target_market": ["Kazakhstan"],
  "language_plan": ["English", "Russian"],
  "approved_facts": [],
  "available_evidence": [],
  "missing_high_risk_facts": [],
  "asset_plan": [],
  "primary_cta": "request_sample",
  "forbidden_claims": []
}
```

合作路线必须唯一：`oem_odm`、`wholesale_distribution` 或 `consumer_retail`。系统默认 B2B；只有用户明确选择时才使用 C 端零售逻辑。

### 已确认决策：合作路线的配置归属

合作路线属于企业长期经营模型，作为“社媒策略”独立资料保存在企业中心。该资料由系统根据公司与市场、产品资料、报价与业务规则、素材库等已有信息自动填写；客户可直接修改表单，不需要从零手动配置。

页面结构：

- `企业中心 → 资料区 → 公司与市场`：展示社媒策略摘要卡，与公司/市场信息关联，并可进入详情。
- `企业中心 → 资料区 → 社媒策略`：独立资料页，保存路线、默认买家、CTA 和渠道等策略字段。

- 企业中心仅启用一项路线时，每次脚本生成自动继承该路线。
- 企业中心启用多项路线时，工作台“选模式”步骤必须要求用户为本条视频确认唯一合作路线；未确认不得开始脚本生成。
- 已确认路线随草稿保存，并据此限定买家问题、证据顺序和主 CTA。
- 企业中心后续修改只影响新建或重新生成的脚本，不静默改写已确认草稿。

### 企业中心：每条合作路线的选择题

系统对每个已启用的合作路线自动生成一组策略表单。所有答案由脚本自动继承，不由模型在脚本生成时临时猜测；客户可以在社媒策略页修改：

1. **默认目标买家**：多选，且用户排序即优先级。初始选项为：
   - OEM / ODM：品牌创始人、产品经理、采购。
   - 现货批发 / 经销：进口商、经销商、渠道采购。
   - C 端零售：终端消费者。
2. **默认主 CTA**：单选。每条视频仍只能使用一个主 CTA；用户可在生成草稿时按需要改写措辞，但不得切换为未配置的业务目标。
3. **已验证承接渠道**：多选。WhatsApp、表单、私信、官网链接均属于受验证渠道：只有已选择且实际配置/验证通过的渠道，才能写入 CTA；未验证时即使只出现渠道名称也不得生成。

企业中心配置的目标买家、主 CTA 和渠道是“默认策略”，不是不可变的事实；草稿中可在权限范围内覆盖，但覆盖值必须随草稿保存并参与生成后质检。

在“AI 创作工作台 → 视频模式 → 选择主题/分镜”中，主 CTA 以企业中心默认文案预填，用户直接编辑本条视频的 CTA；不提供 CTA 目标单选器。系统在保存、生成和发布时校验 CTA 是否保持一个主要行动，以及所引用的 WhatsApp、表单、私信或官网是否已验证。

同一页面中的目标买家以企业中心默认角色及优先级预填；用户可直接改写为本条视频的具体买家描述。该覆盖值只随当前草稿保存，不反向修改企业中心。

## 产品信息模式的资产边界

产品信息模式可设计可执行拍法，但必须为每个镜头/证据标识状态：

- `available`：企业已有素材，可直接使用。
- `suggested_shoot`：建议补拍的创意，不得描述为既有企业事实。
- `evidence_required`：补齐证明后才能使用。
- `forbidden_claim`：当前禁止当作事实生成或拍摄。

资料缺少名称或品类时阻止生成；其他高风险事实（价格、MOQ、认证、交期、功效、案例、产能等）缺失时，生成保守稿并返回待确认项，不得猜测补齐。

分镜数量由时长、信息密度、主题和素材覆盖在后台静默决定，而非固定五段：15 秒通常为 3–4 段，20–30 秒通常为 5–6 段，45–60 秒通常为 7–9 段。前端不展示预计分镜数、镜头密度或推理过程，也不提供相应调节入口；只展示最终脚本，用户可直接编辑成稿。

### 企业文件：双入口、智能同步

企业中心提供两个上传入口：

- `企业中心 → 产品资料 → 产品卡片 → 证书/产品文件`：单品相关的证书、检测、包装或产品文件。
- `企业中心 → 报价与业务规则 → 业务资料`：报价、MOQ、交期、案例授权及企业级文件。

每份文件只保存一个规范记录。AI 自动识别其类型与关联产品，并把同一文件同步展示在相关产品卡和/或业务资料区；用户不需要重复上传或手动打标。

社媒策略自动同步时，AI 只更新尚未被客户编辑的字段。客户编辑过的字段标记为“已手动修改”并保持原值；公司、产品、业务规则或素材变化不得静默覆盖该字段。

## 自动生成约束与风险提示

以下问题应阻止系统将相应内容自动写入，或在脚本预览中提示风险；它们不禁用客户的发布操作：

1. 同一视频混用多条合作路线，或没有唯一主 CTA。
2. CTA 指向不可访问、未验证归属或未绑定的渠道。
   WhatsApp、表单、私信和官网链接未验证时，一律视为不可用渠道。
3. 将未确认的功效、认证、检测、客户案例、出口国家、MOQ、价格、交期、产能、库存或合作结果写成事实。
4. 把消费者互动、评论或点赞包装为 B2B 采购证明。
5. 将竞品/对标/语料账号的数字、资质、案例或反馈迁移为当前企业事实。
6. 素材库模式编造不存在的画面、动作、人物身份、生产场景或结果。
7. 多语版本新增事实承诺，或专有名词读法未按配置处理。

## 软约束与质量评分

- 前 1–3 秒应提供明确停留理由：问题、结果预告、反差、场景、趋势或具体利益。
- 每个分镜承担不同功能；重复功能应合并或降分。
- 卖点必须嵌入画面、参数、流程或可见证据，避免“高品质、专业、值得信赖”等空泛形容词。
- 中段至少出现一个可信证明动作或证据。
- B2B 内容应回答买家决策问题：适合谁、为什么可信、如何开发/打样/合作、下一步如何确认。
- 冷启动或信任不足时，CTA 可选择关注、领取目录或咨询样品，不默认强促销。

## 主题可用性

前端保留全部九个主题，但应显示“可生成 / 需补资料 / 暂不可用”，并在自动匹配时优先选择证据充分的主题。

- 默认可用：买家痛点、使用场景、真人口播（仍需基本产品事实，真人身份不得虚构）。
- 需要产品或素材证据：产品实证、供应能力、定制能力。
- 需要至少两个可比对象：选型对比。
- 需要已授权、可核实资料：客户案例。
- 需要可靠外部来源：趋势热点。

## 行业与市场策略

行业语料用于检索增强、策略归纳与质量评测，不直接训练模型，也不将原文、数字、案例或资质迁移进商家脚本。

策略组装顺序为：

`内容主题策略 + 平台/时长策略 + 目标市场策略 + 行业策略卡 + 企业产品事实`

首批行业策略卡重点服务美妆护肤外贸工厂与中亚市场，并记录适用市场、语言、平台、来源和采集时间。研究重点是 B 端买家的停留因素、信任证据、询盘语言与反感表达，而不是收集可照抄的“爆款句子”。

## 后续实施优先级
