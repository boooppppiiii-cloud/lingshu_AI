## 问题记录

### P01 企业资料为空导致生成入口阻塞

- 现象：四个可登录客户空间均没有产品；当前账号也没有主要输出语言。
- 前端结果：产品选择显示“暂无可选产品”；点击生成后提示需先配置企业中心语言。
- 处理：通过企业中心前端配置英语，并添加最小测试产品“OEM 滴管精华瓶”。
- 状态：已解除阻塞。

### P02 企业中心多选下拉互相覆盖

- 现象：目标市场与主要语言两个 `<details>` 可同时展开；菜单重叠后点击“北美”实际勾选“阿拉伯语”。
- 修复：同组 `<details>` 增加相同 `name` 以互斥展开；复选框增加 `aria-label`。
- 状态：代码已修，待 UI 回归。

### P03 本任务后端端口冲突

- 现象：`8790` 已被其它进程占用，本任务 watch 后端启动失败，前端误连既有后端。
- 修复：本任务使用独立稳定后端 `8792`，前端代理指向 `8792`。
- 状态：已解决。

### P04 watch 后端被其它会话修改中断

- 现象：共享仓库中的其它进程持续修改 `server/routes/videos.ts`，触发 `tsx watch` 重启；生成请求被中断，登录态回到登录页。
- 修复：测试后端改为不监听文件变化的 `tsx server/index.ts`；代码修复后手工重启。
- 状态：已解决。

### P05 前端 45 秒超时早于后端校验完成

- 现象：前端 45 秒返回“后端模型生成超过 45 秒”，后端随后才完成多轮修稿并返回结果。
- 修复：前端生成等待上限改为 120 秒。
- 状态：代码已修，待最终回归。

### P06 字幕/台词差异触发无谓的三轮模型修复

- 现象：首稿已生成，但四段均因字幕与台词不一致进入额外修复，最终仍拒绝。
- 修复：确定性的字幕同步前置到模型修复之前；缺失字幕时直接根据台词补齐。
- 状态：代码已修，待最终回归。

### P07 分镜字段一行输出导致校验失效

- 现象：模型把时间戳、素材和九个字段输出在同一行；后端只识别行首字段，因此漏检缺失字幕。
- 修复：校验前把时间戳和各字段规范化为独立行。
- 状态：代码已修，待最终回归。

### P08 台词被机械截断成半句话

- 现象：出现“怎么判断这款包”“滴管结”等硬截断文本，但后端仍放行。
- 原因：`fitSpeechToShot` 按字符数直接裁切，隐藏了原始超时问题。
- 修复：素材模式不再机械裁切；保留完整台词并交给语义修稿和时长校验处理。
- 状态：代码已修，待最终回归。

### P09 跨语言 CTA 被误判并生成后台配置口吻

- 现象：英文脚本使用 DM/message 时校验不认；修稿后口播变成“引导跳转WhatsApp以触达”。
- 修复：WhatsApp CTA 接受 DM/direct message/message us 等自然英文表达；提示词要求按输出语言自然翻译动作语义，禁止朗读后台配置措辞。
- 状态：代码已修，待最终回归。

### P10 PocketBase 缺少 studio_projects 集合

- 现象：每次草稿创建/更新均记录 `Missing or invalid collection context` 404。
- 影响：本地降级保存可继续，但云端草稿持久化不可用，日志噪声较大。
- 状态：待单独修复或补迁移；不阻塞脚本矩阵测试。

## 已观察的生成结果

### 素材库智能生成 × 买家痛点

1. 初次：45 秒前端超时；后端因四段字幕/台词不一致拒绝。
2. 字幕同步修复后：约 55 秒成功，但台词被硬截断且只有一行字幕。
3. 去除硬截断后：约 90 秒成功，台词完整，但字段分块正则未识别字幕，CTA 仍为后台配置口吻。
4. 当前：已修复分块正则、字幕补齐和跨语言 CTA，等待稳定后端重启后的最终回归。
