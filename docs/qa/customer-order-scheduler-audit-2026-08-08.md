## 缺陷清单

### P1：客户分组切换后详情仍显示上一个分组的客户

- 路径：我的客户。
- 操作：先选中“潜客”中的客户，再切换到“成交客户”或“沉默客户”。
- 实际：左侧列表正确切换，但右侧详情仍展示原客户；该客户不属于当前列表。
- 预期：切换分组时自动选择当前分组首个客户，或清空详情并提示选择。
- 风险：运营人员可能在错误客户上下文执行生成草稿、建单或人工跟进。

### P1：视频分析汇总、状态分布和卡片状态互相矛盾

- 路径：定时任务 → 我的社媒定时任务 → 视频分析。
- 实际：4 张卡片最初均显示“已分析”，汇总却显示“已分析 0”，状态分布为 `none: 4`。重新分析一条失败后，汇总显示“已分析 1”，但卡片实际为 3 条已分析、1 条失败，状态分布仍保留旧值。
- 预期：汇总、分布和列表使用同一状态归一化逻辑，并在自动刷新后同步更新。

### P1：视频分析失败直接暴露服务器内部命令和文件路径

- 路径：视频分析队列 → 重新分析。
- 实际：失败卡片完整展示 `python3 -m yt_dlp` 命令、User-Agent、`/app/data/analysis-temp/...` 路径及参数。
- 预期：前端只展示脱敏错误码和可操作提示；完整 stderr 仅进入服务端日志。
- 风险：泄露部署目录、依赖和调用参数，也显著破坏页面可读性。

### P1：定时任务“新建任务”按钮无响应

- 路径：定时任务 → 老客唤醒定时任务 → 新建任务。
- 实际：点击后无弹窗、抽屉、跳转或错误提示。
- 预期：打开自定义任务表单；若当前类别仅支持模板创建，应禁用按钮并说明原因。

### P2：订单状态更新后辅助文本仍保留旧状态

- 路径：我的订单 → 行内状态选择。
- 操作：将 `LS-20260807-002` 从“已付款”改为“已发货”。
- 实际：可见状态和待履约指标正确更新，但表格行/单元格的辅助名称仍包含“已付款”。
- 预期：可访问名称和可见状态同时更新。
