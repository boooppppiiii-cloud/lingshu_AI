# 普通用户社媒配置小白教程

这份教程适用于灵枢普通用户。你可以把自己申请的 Google、Meta 或 TikTok 应用凭证直接保存到自己的企业空间，再授权自己的社媒账号。各用户的凭证和账号相互隔离，Secret 会加密保存。

## 一、先打开配置入口

1. 登录灵枢工作台：`https://app.lingshu.site/`。
2. 点击左侧“集成中心”。
3. 展开页面顶部“配置我自己的社媒应用”。
4. 页面会显示每个平台需要填写的凭证，以及可以一键复制的回调地址。

重要：回调地址必须直接复制页面显示的内容，不要手打。`https`、域名、路径和末尾斜杠只要有一个字符不同，授权都会失败。

## 二、只配置你要使用的平台

不需要一次配置全部平台。例如只想发 YouTube，就只填写 YouTube / Google 卡片，其他卡片留空即可。

### YouTube / Google

1. 打开 [Google Cloud Console](https://console.cloud.google.com/)，新建或选择项目。
2. 启用 YouTube Data API v3。
3. 配置 OAuth 同意屏幕。
4. 创建“Web 应用”类型的 OAuth 客户端。
5. 在 Google 后台的 Authorized redirect URIs 中，粘贴灵枢页面的 YouTube 回调地址。
6. 把 Google 给出的 Client ID 和 Client Secret 填回灵枢。

### Instagram / Facebook

1. 打开 [Meta for Developers](https://developers.facebook.com/)，创建一个 Meta App。
2. 为应用添加 Facebook Login、Instagram Graph API 等实际需要的产品和权限。
3. 把灵枢页面显示的 Instagram 和 Facebook 两条回调地址都加入 Meta 后台的 Valid OAuth Redirect URIs。
4. 在 App Settings → Basic 找到 App ID 和 App Secret，并填回灵枢。
5. Instagram 发布通常要求专业账号，并关联一个 Facebook Page。

### TikTok

1. 打开 [TikTok for Developers](https://developers.tiktok.com/)，创建应用。
2. 添加 Login Kit 和 Content Posting API。
3. 把灵枢页面显示的 TikTok 回调地址加入应用的 Redirect URI。
4. 把 Client Key 和 Client Secret 填回灵枢。
5. TikTok 的发布权限可能需要平台审核；未通过审核时只能使用平台允许的测试账号或测试范围。

## 三、保存并连接账号

1. 点击“保存我的平台凭证”。
2. 看到绿色保存成功提示后，Secret 输入框会清空，这是正常的安全设计，不是保存失败。
3. 页面显示“已填写”就表示 Secret 已安全保存；以后不修改 Secret 时保持输入框为空即可。
4. 向下找到对应平台卡片，点击“连接”或“授权”。
5. 在平台官方页面登录，选择正确的频道、主页或专业账号，并同意权限。
6. 返回灵枢，确认平台卡片显示已连接。

## 四、常见问题

- 提示 redirect URI 不匹配：重新复制灵枢页面地址，并逐字核对平台后台配置。
- 提示 Client ID 或 Secret 错误：确认两者来自同一个开发者应用；重新填写 Secret 并保存。
- Meta 找不到 Instagram 账号：确认 Instagram 已切换为专业账号，并已关联 Facebook Page。
- TikTok 或 Meta 能登录但不能发布：通常是应用权限尚未审核、账号不在测试名单，或没有授予发布权限。
- 更换 Secret：只需在对应 Secret 输入框填入新值并保存；其他已保存 Secret 留空，不会被删除。

## 五、安全提醒

- 不要把 Client Secret、App Secret、Access Token 发到微信群、邮件或普通表格。
- 只在灵枢的 HTTPS 正式域名中填写凭证。
- 建议为平台管理员账号开启双重验证。
- 如果怀疑 Secret 泄露，立即到对应平台后台重置，再回灵枢填写新 Secret。
