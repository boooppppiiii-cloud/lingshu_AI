# 灵枢集成中心：社媒与 WhatsApp 账号自助连接教程

适用对象：灵枢普通用户。按照本教程操作，你可以在自己的企业空间中配置 Google、Meta、TikTok 应用，并连接 YouTube、Instagram、Facebook、TikTok 和 WhatsApp Business 账号。

## 一、先看完整流程

整个操作只分两步：

1. 在各平台的开发者后台创建应用，把平台给出的 App ID、Client ID、Client Key 和 Secret 填入灵枢。
2. 在灵枢页面下方点击对应账号的“连接”或“授权”，登录平台并确认授权。

你只需要配置实际要使用的平台。例如只连接 YouTube，就只操作 Google / YouTube 部分，其他卡片可以暂时不填。

## 二、进入灵枢集成中心

1. 打开 `https://app.lingshu.site/` 并登录自己的灵枢账号。
2. 点击左侧菜单中的“集成中心”。
3. 展开页面顶部的“配置我自己的社媒应用”。
4. 页面会显示三张配置卡片：YouTube / Google、Instagram / Facebook / WhatsApp、TikTok。
5. 每张卡片下面都有可复制的回调地址。回调地址直接点击“复制”，不要手动输入。

完成平台应用配置后，向下滚动页面，即可看到 YouTube、Instagram、Facebook、TikTok 和 WhatsApp 的连接卡片。

## 三、连接 YouTube / Google

### 3.1 在 Google Cloud 创建应用

1. 打开 `https://console.cloud.google.com/`，登录要管理 YouTube 频道的 Google 账号。
2. 在顶部选择一个已有项目，或者点击“新建项目”。
3. 打开“API 和服务”→“库”。
4. 搜索 `YouTube Data API v3`，进入后点击“启用”。
5. 返回“API 和服务”，打开“OAuth 同意屏幕”。
6. 按页面提示填写应用名称和联系邮箱，并保存。
7. 打开“凭据”，点击“创建凭据”→“OAuth 客户端 ID”。
8. 应用类型选择“Web 应用”。

### 3.2 填写回调地址

1. 回到灵枢集成中心，在 YouTube / Google 卡片中复制 `Authorized redirect URI`。
2. 回到 Google Cloud，把地址粘贴到“已获授权的重定向 URI”。
3. 正式环境的地址应为：`https://app.lingshu.site/api/overseas/youtube/oauth/callback`。
4. 点击“创建”。

### 3.3 保存并授权频道

1. Google 会显示 `Client ID` 和 `Client Secret`。
2. 把两项内容分别填入灵枢的 YouTube / Google 卡片。
3. 点击“保存我的平台凭证”。
4. 页面提示保存成功后，向下找到 YouTube 卡片并点击“连接 YouTube”或“授权”。
5. 在 Google 官方页面选择要连接的账号和频道，点击“允许”。
6. 返回灵枢，卡片显示“已连接”即完成。

## 四、连接 Instagram 和 Facebook

Instagram、Facebook 和 WhatsApp 共用同一个 Meta App，所以 Meta App 只需要创建一次。

### 4.1 创建 Meta App

1. 打开 `https://developers.facebook.com/`，登录管理 Facebook Page 的 Meta 账号。
2. 点击“My Apps”→“Create App”。
3. 按页面提示选择业务用途并创建应用。
4. 在 App Dashboard 中添加需要使用的产品，例如 Facebook Login、Instagram Graph API 和 WhatsApp。
5. 打开“App Settings”→“Basic”，找到 `App ID` 和 `App Secret`。

### 4.2 配置 Instagram 和 Facebook 回调地址

1. 回到灵枢 Meta 卡片，分别复制 `Instagram redirect URI` 和 `Facebook redirect URI`。
2. 在 Meta 后台的 Facebook Login 设置中找到 `Valid OAuth Redirect URIs`。
3. 把两条地址分别粘贴进去并保存。
4. 正式环境地址分别为：
   - Instagram：`https://app.lingshu.site/api/overseas/social/oauth/instagram/callback`
   - Facebook：`https://app.lingshu.site/api/overseas/social/oauth/facebook/callback`
5. 把 Meta 的 `App ID` 和 `App Secret` 填入灵枢 Meta 卡片。
6. 点击“保存我的平台凭证”。

### 4.3 授权 Facebook

1. 向下找到 Facebook 卡片，点击“连接 Facebook”。
2. 在 Meta 官方页面登录并选择正确的 Facebook Page。
3. 勾选页面需要的管理和发布权限，完成授权。
4. 返回灵枢，确认 Facebook 卡片显示“已连接”。

### 4.4 授权 Instagram

1. 先确认 Instagram 已切换为专业账号，并已关联一个 Facebook Page。
2. 在灵枢找到 Instagram 卡片，点击“连接 Instagram”。
3. 在 Meta 官方页面选择正确的 Instagram 专业账号和关联主页。
4. 完成授权后返回灵枢，确认 Instagram 卡片显示“已连接”。

## 五、连接 WhatsApp Business

WhatsApp 使用同一个 Meta App。完成下面配置后，可以直接在灵枢中打开 Meta 官方的一键授权窗口。

### 5.1 创建 Embedded Signup 配置

1. 在 Meta App Dashboard 中打开 WhatsApp 产品。
2. 找到 Embedded Signup（嵌入式注册）配置入口。
3. 新建一个配置，并按页面提示选择 WhatsApp Business 管理和消息权限。
4. 保存后复制 `Configuration ID`，也就是灵枢页面中的 `Embedded Signup Config ID`。
5. 把这个 ID 填入灵枢 Meta 卡片。

### 5.2 配置 WhatsApp Webhook

1. 在灵枢 Meta 卡片中复制 `WhatsApp Webhook Callback URL`。
2. 再复制 `WhatsApp Webhook Verify Token`。
3. 回到 Meta 后台 WhatsApp → Configuration，把两项分别粘贴到 Callback URL 和 Verify Token。
4. 点击 Meta 页面中的“Verify and Save”。
5. 在 Webhook fields 中订阅 `messages`；如果页面提供消息状态字段，也一并订阅。
6. 回到灵枢，点击“保存我的平台凭证”。

### 5.3 一键连接 WhatsApp 号码

1. 向下找到“WhatsApp Business 一键授权”卡片。
2. 点击“连接 WhatsApp”。
3. 在 Meta 官方弹窗中登录 Facebook。
4. 选择或创建 Business Portfolio。
5. 选择或创建 WhatsApp Business Account。
6. 选择已有号码，或按 Meta 页面提示添加新号码并完成验证码验证。
7. 点击完成，等待弹窗自动关闭。
8. 返回灵枢后，卡片会显示“WhatsApp Business 已连接”、号码和 Phone Number ID。

## 六、连接 TikTok

### 6.1 创建 TikTok 应用

1. 打开 `https://developers.tiktok.com/` 并登录。
2. 进入开发者控制台，点击创建应用。
3. 为应用添加 `Login Kit` 和 `Content Posting API`。
4. 应用类型选择 Web。

### 6.2 配置回调并保存凭证

1. 回到灵枢 TikTok 卡片，复制 `Redirect URI`。
2. 在 TikTok 应用后台的 Redirect URI 中粘贴该地址。
3. 正式环境地址应为：`https://app.lingshu.site/api/overseas/social/oauth/tiktok/callback`。
4. 保存 TikTok 应用设置。
5. 复制 TikTok 提供的 `Client Key` 和 `Client Secret`，填回灵枢。
6. 点击“保存我的平台凭证”。
7. 如果 TikTok 页面要求验证域名，按页面提示完成 `lingshu.site` 的域名验证后再继续。

### 6.3 授权 TikTok 账号

1. 向下找到 TikTok 卡片，点击“连接 TikTok”。
2. 在 TikTok 官方页面登录要发布内容的账号。
3. 确认授权范围并完成授权。
4. 返回灵枢，卡片显示“已连接”即完成。

## 七、如何确认连接成功

逐项检查：

1. 平台配置卡片中的 ID 已显示，Secret 旁边显示“已填写”或“已安全保存”。
2. 对应账号连接卡片显示“已连接”。
3. WhatsApp 卡片显示号码或 Phone Number ID。
4. 进入“一键发布”后，可以在“平台账号选择”中看到已连接的 YouTube、Instagram、Facebook 或 TikTok 账号。
5. WhatsApp 收到客户消息后，可以在“我的客户”中看到对应会话。

## 八、常见问题处理

### 提示 redirect URI 不匹配

重新从灵枢点击“复制”，覆盖平台后台原来的地址并保存。重点核对 `https`、`app.lingshu.site` 和完整路径。

### 保存后 Secret 输入框变空

这是正常现象。页面显示“已填写”说明 Secret 已保存；以后不修改 Secret 时保持空白即可。

### Facebook 能连接，Instagram 找不到账号

确认 Instagram 已切换为专业账号，并关联到当前登录账号有管理权限的 Facebook Page。

### WhatsApp 点击连接时提示缺少配置

回到页面顶部 Meta 卡片，确认 App ID、App Secret 和 Embedded Signup Config ID 都已经填写并保存。

### WhatsApp 授权完成后没有显示号码

先点击 WhatsApp 卡片右上角的刷新按钮；仍未显示时，重新点击“连接 WhatsApp”并完整走完 Meta 弹窗。

### TikTok 可以登录但不能发布

检查 Content Posting API 是否已经添加、发布权限是否通过审核，以及当前账号是否在 TikTok 应用允许的测试或正式范围内。

### 需要更换 Secret

在对应 Secret 输入框填入新值并重新保存。其他不需要修改的 Secret 保持空白，不会被删除。

只需注意一件事：App Secret、Client Secret 和 Access Token 直接填在灵枢页面中，不要发到聊天窗口。
