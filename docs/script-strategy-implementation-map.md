# 社媒脚本策略实施地图

本地图以已确认的策略决策为准，列出当前代码与目标体验的差异。实施时按页面分组，避免把后台策略改动误做成额外前端控件。

## 1. 企业中心：独立社媒策略资料

**目标页面**

- `企业中心 → 资料区 → 公司与市场`：社媒策略摘要卡及详情入口。
- `企业中心 → 资料区 → 社媒策略`：独立策略资料页。

**目标行为**

- 根据公司与市场、产品资料、报价与业务规则、素材库自动填充路线、默认买家、CTA 与渠道状态。
- 客户可以编辑字段；已编辑字段不被后续同步静默覆盖。
- WhatsApp、表单、私信、官网状态只从对应连接/配置页同步读取。

**现有落点**

- [EnterprisePage.tsx](../src/components/EnterprisePage.tsx)：当前事实区只有“公司与市场 / 产品资料 / 素材库”三个 Tab，需要新增社媒策略资料与持久化字段。
- `server/strategy/scriptBrief.ts`：已提供策略资料与路线的技术契约，尚未接入企业资料保存或接口。

## 2. 工作台：主题、买家与 CTA

**目标页面**

- `AI 创作工作台 → 视频模式 → 选择主题/分镜`。

**目标行为**

- AI 推荐主题，用户可切换任意九个主题；切换不会使现有素材失效。
- 移除“潜在客户核心痛点”输入框。
- 目标买家、CTA 由企业社媒策略预填，支持本条视频直接编辑并随草稿保存。
- CTA 不提供目标单选器；保存、生成时仅静默校验唯一行动及已验证渠道引用。
- 现有 `themeConversionGoal` 是主题级 CTA 来源；接入策略层时删除其对请求与 Prompt 的影响，统一改用草稿 `primaryCta`。

**现有落点**

- [AiCreateStudio.tsx](../src/components/AiCreateStudio.tsx)：主题卡片当前存在可用性禁用规则；仍显示痛点、转化目标输入框；需要接入企业社媒策略默认值。
- [studio.ts](../server/routes/studio.ts)：主题 Prompt 当前直接接收痛点和转化目标，需要改为消费策略 Brief 与本条草稿覆盖值。

## 3. 素材库智能生成：上传、缺口与待拍

**目标页面**

- `AI 创作工作台 → 视频模式 → 素材库智能生成 → 选素材 → 左侧素材库 → 上传素材`。
- `灵感大屏 → 待拍 Tab`。

**目标行为**

- 用户只上传文件；AI 自动分类、关联产品、打镜头功能标签，不要求填写或确认标签。
- 上传后自动加入当前素材组合；若来自“选择其他素材”，成为该缺口优先候选。
- 缺少理想镜头不阻断生成或成片：提供“选择其他素材 / 创建建议补拍”。
- 建议补拍进入待拍队列，标记“脚本缺口”与作品集来源；上传后不自动回填，用户点击“一键回填”才作用于仍存在的原分镜。

**现有落点**

- [AiCreateStudio.tsx](../src/components/AiCreateStudio.tsx)：已有素材上传、自动选中和文件夹，但需要补齐无阻断缺口卡、待拍任务创建与回填入口。
- [studio.ts](../server/routes/studio.ts)：已有视频分段识别、OCR、主体/动作/镜头标签；需要把自动标签结构化并持久化。
- `server/strategy/scriptBrief.ts`：已定义视觉能力、建议补拍任务与主题覆盖的技术契约，尚未接入任务存储/API。

## 4. 产品信息生成：动态分镜

**目标页面**

- `AI 创作工作台 → 视频模式 → 产品信息生成 → 选择主题/分镜`。

**目标行为**

- 分镜数量在后台根据时长、主题和素材静默决定；前端不显示预计数量、规则或调节入口。
- 不自动创建待拍任务；仅用户从具体分镜主动创建时才入待拍队列。

**现有落点**

- [studio.ts](../server/routes/studio.ts)：产品模式当前强制五段，是主要后端改造点。

## 5. 爆款裂变：静默迁移、完整分析前置

**目标页面**

- `AI 创作工作台 → 视频模式 → 爆款裂变 → 对标视频分析状态`。

**目标行为**

- 只显示“正在分析镜头…”或“镜头分析完成，可生成裂变脚本”。
- 对标视频必须完成连续全片逐镜分析；未完成时生成按钮不可用。
- 高保真/结构迁移/机制借鉴在后台静默选择，前端不展示、不让用户选择。

**现有落点**

- [studio.ts](../server/routes/studio.ts)：全片逐镜分析前置已基本具备。
- [AiCreateStudio.tsx](../src/components/AiCreateStudio.tsx)：仍展示迁移方式与相关选择控件，需要移除或隐藏。

## 6. 预览、发布与多语

**目标页面**

- `AI 创作工作台 → 视频模式 → 脚本/分镜预览`。
- `AI 创作工作台 → 视频模式 → 选择声音策略 → 提取口播与多语种字幕`。

**目标行为**

- 后台静默修正钩子、重复、时长、CTA 和事实问题；前端仅在具体句子/分镜显示“待确认”。
- 待确认不禁用编辑、预览或发布，不提供额外处理/跳转功能。
- 复用现有口播提取、翻译、TTS 和字幕对齐能力；不在脚本生成页新增语言策略或多份主脚本配置。

**现有落点**

- [AiCreateStudio.tsx](../src/components/AiCreateStudio.tsx)：多语口播流程已有；需要补齐待确认的轻量定位显示。
- [studio.ts](../server/routes/studio.ts)：需要把静默质检与事实提示区分开，避免将策略风险变成发布阻断。
