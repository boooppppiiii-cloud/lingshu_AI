# 社媒脚本策略决策日志

本文件区分已确认产品决策与待讨论提案。只有“已确认”规则可进入企业中心、策略 Brief、Prompt 或发布质检。

## 已确认

| 决策 | 规则 |
| --- | --- |
| 企业社媒策略资料 | “社媒策略”是企业中心独立资料，由系统根据公司与市场、产品资料、报价与业务规则、素材库自动填充；客户可直接修改表单。 |
| 企业合作路线 | 社媒策略资料中可多选 OEM/ODM、现货批发/经销、C 端零售。 |
| 社媒策略同步 | 在“企业中心 → 资料区 → 社媒策略”中，AI 仅自动更新未被客户编辑的字段；客户编辑过的字段标记“已手动修改”并保留，后续企业资料变化不得静默覆盖。 |
| 承接渠道验证 | 在“企业中心 → 资料区 → 社媒策略 → 承接渠道”中，只自动同步展示 WhatsApp、表单、私信、官网的验证状态，不允许手动标记验证；渠道本身只能在对应账号连接或官网配置页修改。 |
| 单条视频路线 | 企业仅启用一条时自动继承；启用多条时，用户必须在工作台“选模式”步骤确认本条视频的唯一路线。 |
| 路线配置 | 企业中心按已启用路线配置默认目标买家（多选、排序即优先级）、默认主 CTA（单选）和已验证承接渠道（多选）。 |
| OEM/ODM 默认买家优先级 | 默认顺序为品牌创始人、产品经理、采购；品牌创始人是新脚本的默认买家。 |
| 路线默认主 CTA | OEM/ODM、现货批发/经销、C 端零售统一沿用当前默认“引导跳转 WhatsApp 以触达”。仅当企业 WhatsApp 已配置并验证时才自动预填。 |
| CTA 渠道 | WhatsApp、表单、私信、官网链接未完成企业配置与验证时，不得出现在脚本 CTA 中。 |
| 路线与主题 | 二者独立。路线提供商业目标、默认买家、CTA 与渠道；主题提供叙事结构及自身证据要求。不得以路线和主题的组合判定脚本不合法。 |
| 主题准入 | 对应主题只要具备最低画面素材，即可进入脚本策略；高风险事实缺失不得阻断主题。它们仅限制系统自动生成的相应主张，不限制客户发布。 |
| 最低素材判断 | 按主题所需的镜头功能组合判断，而非上传文件数量。 |
| 素材标签 | 所有画面功能标签由 AI 自动识别并直接用于主题最低素材判断，不要求用户确认；高风险事实主张另行校验。 |
| 素材不足处理 | 在“AI 创作工作台 → 视频模式 → 素材库智能生成 → 选素材”中，缺少理想镜头时不得自动切换到产品信息生成，也不得判定现有相关素材不合法或阻止生成/成片。页面提示缺失项，提供“选择其他素材 / 创建建议补拍”；系统基于当前相关素材调整分镜。 |
| 选择其他素材 | 在同一页面打开右侧素材抽屉，只筛选当前产品相关的全部素材，不要求 AI 标签完全匹配。用户选中后加入当前素材组合，系统重新生成分镜，无需用户理解或手动匹配标签。 |
| 创建建议补拍 | 在“AI 创作工作台 → 视频模式 → 素材库智能生成 → 缺口卡”点击后，同步到“灵感大屏 → 待拍 Tab”队列。任务携带产品、主题、待补镜头功能、拍摄说明、建议时长和来源草稿/分镜，后续可上传并回填。 |
| 待拍回填 | 待拍任务标记为“脚本缺口”并显示作品集来源。上传素材后不自动回填；用户点击“一键回填”时，才回填至仍存在的来源分镜，且不重写整条脚本。 |
| 补拍素材入库 | 待拍任务上传的补拍素材自动进入企业素材库，保留任务/作品集来源和 AI 标签，可被同企业其他作品复用。 |
| 一键回填边界 | 仅在来源草稿及原分镜仍存在时，回填至原分镜且不重写整条脚本。若来源已重新生成、原分镜已删除或项目不存在，按钮置灰并引导用户进入作品集手动选择，禁止猜测性回填。 |
| 素材库主题选择 | 在“AI 创作工作台 → 视频模式 → 选择主题/分镜”中，AI 先根据当前素材推荐并选中一个主题；用户可切换九个主题。切换只重新组织钩子、分镜顺序和素材用途，不否定已选素材；缺口继续提供选择其他素材/创建建议补拍。 |
| 本条视频 CTA | 在“AI 创作工作台 → 视频模式 → 选择主题/分镜”中，主 CTA 以企业中心默认文案预填，用户直接编辑，不提供 CTA 目标单选器；随草稿保存。保存、生成、发布时校验唯一主 CTA 及已验证承接渠道。 |
| 本条视频买家 | 同一页面以企业中心默认买家角色及优先级预填；用户可直接改写为本条视频的具体买家描述，仅随当前草稿保存。 |
| 核心痛点输入 | 在“AI 创作工作台 → 视频模式 → 选择主题/分镜”中移除“潜在客户核心痛点”输入框。系统静默组合主题、产品、目标买家和企业社媒策略；用户只编辑目标买家、CTA 与最终脚本。 |
| 主题脚本版本 | 在“AI 创作工作台 → 视频模式 → 选择主题/分镜”中切换主题不覆盖当前脚本；当前主题脚本默认保留。用户点击“生成可执行分镜”后，自动为新主题创建新脚本版本，命名为“主题 · 买家（序号）”，如“买家痛点 · 美国采购版（1）”。 |
| 主题 Prompt | 使用“共享外贸工厂底座 + 主题约束卡”。主题约束只控制钩子、证明顺序、镜头功能、可用画面和禁用表达；不维护九套完整大 Prompt，不改变事实边界，也不以路线/主题组合阻断脚本。CTA 不属于主题策略，始终只使用当前草稿的唯一主 CTA。 |
| 分镜密度 | 在“AI 创作工作台 → 视频模式 → 选择主题/分镜”中，分镜数量和密度由系统静默决定。前端不显示预计分镜数、推理过程或调节入口，只展示最终脚本；用户可编辑最终成稿。 |
| 多语口播 | 复用现有“选择声音策略 → 提取口播与多语种字幕”流程：主脚本后提取口播、翻译字幕/配音并对齐时间，不在脚本生成页新增语言策略或多份主脚本配置。 |
| 爆款裂变迁移 | 在“AI 创作工作台 → 视频模式 → 爆款裂变”中，迁移强度由后台静默判断，前端不展示或让用户选择高保真复刻/结构迁移/机制借鉴；只输出适配企业产品的分镜。竞品事实和独特表达不迁移。 |
| 爆款裂变前提 | 对标视频必须完成全片、连续的逐镜分析，才能生成裂变脚本；不得依据部分分析猜测或补全未识别镜头。 |
| 裂变分析状态 | 在“AI 创作工作台 → 视频模式 → 爆款裂变”中，只显示“正在分析镜头…”或“镜头分析完成，可生成裂变脚本”。分析未完成时生成按钮不可用，不展示时间线缺口、置信度或迁移推理。 |
| 平台策略 | 在“AI 创作工作台 → 视频模式 → 平台选择”中，用户选择发布平台；各平台的节奏、CTA 表达和字幕密度由后台静默适配，不显示或提供平台策略调节。 |
| 质量检查 | 在“AI 创作工作台 → 视频模式 → 脚本/分镜预览”中，钩子、重复分镜、口播时长、CTA 和事实检查均由后台静默修正；前端只显示最终脚本及待确认定位，不显示评分、警告列表或质检报告。 |
| 素材上传 | 在“AI 创作工作台 → 视频模式 → 素材库智能生成 → 选素材 → 左侧素材库 → 上传素材”中，用户只上传文件；AI 自动完成分类、镜头功能和产品关联，用户不填写或确认标签。 |
| 上传完成后 | 同一上传入口完成后，素材自动加入当前视频的素材组合，并在后台分类完成后归入对应文件夹，不展示分析中间态；若从“选择其他素材”进入上传，新素材作为该缺口的优先候选。 |
| 企业文件同步 | 企业中心同时提供“产品资料 → 产品卡片 → 证书/产品文件”和“报价与业务规则 → 业务资料”两个入口。文件只保存一份，AI 自动识别类型与关联产品，并同步展示到相关产品卡和/或业务资料区，无需重复上传或手动打标。 |
| 未识别文件归属 | AI 无法判断产品归属的文件保留在“企业中心 → 报价与业务规则 → 业务资料”，不进入产品卡，也不作为单品脚本事实；不要求用户手动关联。 |
| 企业脚本策略位置 | 在“企业中心 → 资料区 → 公司与市场”Tab 新增“社媒脚本策略”卡片：合作路线（多选）、每条路线的默认买家角色、默认 CTA 文案和已验证承接渠道。工作台继承默认值，单条视频可改写买家与 CTA。 |
| 素材缺口交互 | 在“AI 创作工作台 → 视频模式 → 素材库智能生成 → 选择主题/分镜”中，缺少最低画面时显示“缺少：… / 当前可先生成：…”；只提供“上传替换素材”和“创建建议补拍”。不提供继续生成待补镜头草稿。 |
| 草稿继承 | 路线及其默认策略写入新草稿；企业中心之后的改动不静默改写已确认历史草稿。 |

## 待确认：证据不足时的生成状态

已确认：允许生成可编辑草稿；未被证实的内容标记为 `evidence_required`，系统不得自动写成已发生的企业事实。用户可补证、移除该镜头/主张或保留待确认。草稿可编辑、预览和随时发布；系统不替客户决定是否发布。

页面规则：在“AI 创作工作台 → 视频模式 → 脚本/分镜预览”中，待确认项只定位到具体句子/分镜。草稿始终可编辑、预览和发布；不提供补资料、删改、回填或跳转等额外功能。

## 待讨论顺序

1. 证据不足的草稿可生成范围与风险提示。
2. 九个主题的钩子、证据需求、禁用表达与自动提示。
3. 资产状态与建议补拍的用户确认流程。
4. 素材库素材的证据/氛围/转场能力标签。
5. 爆款裂变三档迁移边界及用户覆盖规则。
6. 动态时长、分镜密度与无口播镜头策略。
7. 平台、市场、语言与多语派生规则。
8. 生成后自动生成拦截、风险提示、优化建议与人工复核。
